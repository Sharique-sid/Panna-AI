# Panna.ai Browser Extension - Installation Guide

## 🚀 Quick Install (Recommended)

### For Chrome/Edge/Brave:
1. **Download the extension** from the link below
2. **Extract the ZIP file** to your computer
3. **Open Chrome** and go to `chrome://extensions/`
4. **Enable "Developer mode"** (toggle in top right)
5. **Click "Load unpacked"**
6. **Select the extracted folder**
7. **Extension is now installed!** 🎉

### For Firefox:
1. **Download the extension** from the link below
2. **Open Firefox** and go to `about:debugging`
3. **Click "This Firefox"**
4. **Click "Load Temporary Add-on"**
5. **Select the manifest.json file** from the extracted folder
6. **Extension is now installed!** 🎉

## 🔧 Manual Installation (Advanced)

If you prefer to build from source:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/mdtaufique-alam/Panna.ai.git
   cd Panna.ai/extension
   ```

2. **Load in browser** (follow steps above)

## ✅ After Installation

1. **Click the Panna.ai icon** in your browser toolbar
2. **Sign in** with your Google account
3. **Start capturing notes** from any website!

## 🆘 Troubleshooting

**Extension not working?**
- Make sure you're signed in to [Panna.ai](https://panna-ai-bice.vercel.app/)
- Check that the extension has permission to access websites
- Try refreshing the page and clicking the extension again

**Need help?**
